#  Car Sales Dashboard

###  Project Overview
This project is an interactive Car Sales Dashboard created using Power BI to analyze sales performance, car trends, company-wise sales, and customer insights.

The dashboard helps users understand:
- Total Sales Performance
- Cars Sold
- Average Price
- Body Style Analysis
- Color-wise Sales
- Company-wise Sales Trends
- Weekly Sales Trends

---

###  Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling
- Excel

---

###  Key KPIs
- YTD Total Sales: $371.2M
- YTD Avg Price: $28.0K
- YTD Cars Sold: 13.3K

---

###  Dashboard Features
- Interactive Filters
- Dynamic KPI Cards
- Weekly Sales Trend Analysis
- Body Style Sales Distribution
- Color-wise Sales Breakdown
- Top 5 Models by Annual Income
- Company-wise Sales Table

---

###  Key Insights
- SUVs generated the highest sales among body styles.
- Pale White cars contributed the highest sales.
- Chevrolet recorded strong YTD sales performance.
- Weekly sales showed significant growth in later weeks.
